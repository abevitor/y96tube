Coloque aqui os binários para macOS:

- yt-dlp -> https://github.com/yt-dlp/yt-dlp/releases (arquivo "yt-dlp_macos", renomeie para "yt-dlp")
- ffmpeg -> `brew install ffmpeg` e copie o binário resultante pra cá

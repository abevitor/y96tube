Coloque aqui os binários para Linux:

- yt-dlp -> https://github.com/yt-dlp/yt-dlp/releases (arquivo "yt-dlp")
- ffmpeg -> instale via `sudo apt install ffmpeg` e copie o binário resultante pra cá,
  ou baixe um build estático em https://johnvansickle.com/ffmpeg/

Dê permissão de execução depois de colocar os arquivos:
chmod +x tools/linux/yt-dlp tools/linux/ffmpeg
